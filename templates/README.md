# gitstamp-art (GitHub Contribution Graph)

This repository contains automated contribution graph artwork generated by [GitStamp](https://kbtale.github.io/gitstamp/).

## Overview

The commits in this repository are calculated and rendered to display custom pixel artwork on the owner's GitHub contribution graph.

## Automation

- **Schedule**: Executes automatically every Sunday at 01:00 UTC via GitHub Actions.
- **Dynamic Centering**: Calculates the rolling 53-week calendar window to keep the artwork centered on the profile graph.
- **Activity Calibration**: Queries the GitHub GraphQL API to detect exact quartile thresholds, ensuring consistent shades across high and low activity periods.
- **Clean History**: Reconstructs the commit history on an orphan branch on every run to prevent repository growth.
